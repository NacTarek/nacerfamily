# شجرة العائلة 🌳

موقع ثابت من ثلاث صفحات، بلا خادم ولا قاعدة بيانات:

| الملف | الوظيفة |
|---|---|
| `index.html` | **واجهة العرض والتصفح** — هذا هو الرابط الذي تعطيه للآخرين. للقراءة فقط: تحريك وتكبير وبحث وطيّ الفروع. |
| `edit.html` | **واجهة التعديل** — تعديل الأسماء، السحب والإفلات، إضافة أبناء وآباء… |
| `tree.json` | **بيانات الشجرة العامة** التي تعرضها واجهة العرض. |

## النشر على GitHub Pages (مرة واحدة)

1. على github.com اضغط **New repository**، سمِّه مثلاً `family-tree`، واختر **Public** (الاستضافة المجانية تشترط ذلك).
2. افتح المستودع ثم **Add file → Upload files**، واسحب إليه الملفات الأربعة: `index.html` و`edit.html` و`tree.json` و`README.md` ثم **Commit changes**.
3. من **Settings → Pages**: في *Source* اختر **Deploy from a branch**، والفرع **main** والمجلد **/ (root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يعمل الرابط:
   - للعرض: `https://اسم-حسابك.github.io/family-tree/`
   - للتعديل: `https://اسم-حسابك.github.io/family-tree/edit.html`

## تحديث الشجرة بعد التعديل

1. عدّل الشجرة في ملفك الخاص على جهازك (`Family Tree.html`) أو في `edit.html`.
2. اضغط **🌐 نشر للعرض** ثم **تنزيل tree.json**.
3. في GitHub افتح المستودع ← **Add file → Upload files** وارفع `tree.json` الجديد (يستبدل القديم) ← **Commit**.
4. يظهر التحديث للزوّار خلال دقائق.

## الحفظ والنشر عبر Supabase ☁️

- **المحرّر** (`edit.html`): يطلب البريد وكلمة السر (تسجيل دخول حقيقي). أول حساب يُنشأ يصبح المالك الوحيد، ولا يستطيع غيره التعديل أو قراءة الاقتراحات.
- **الحفظ**: كل تعديل يُحفظ تلقائيًا في قاعدة بيانات Supabase (نسخة كاملة خاصة بك).
- **النشر**: زر «🌐 نشر للعرض ← نشر الآن للزوّار» يحدّث ما يراه الزوّار فورًا، بدون رفع ملفات.
- **الاقتراحات**: يرسلها الزوّار من العارض، وتصلك في زر «📥 الاقتراحات» داخل المحرّر مع اسم المرسل.
- **العارض** (`index.html`): يقرأ آخر نسخة منشورة من Supabase، و`tree.json` احتياطي إن تعذّر الاتصال.
- الملف `auth.json` لم يعد مستخدمًا ويمكن حذفه من المستودع.

## الخصوصية — مهم

- أي شيء في مستودع عام يراه **كل من يملك الرابط أو يبحث عنه**. ملف `tree.json` يحتوي الأسماء والزوج/الزوجة والتواريخ والمكان.
- النسخة العامة **لا تتضمن** الملاحظات ولا بيانات الدراسة ولا الإنجازات ولا علامات «غير مؤكد». احتفظ بنسختك الكاملة في ملفك الخاص ولا ترفعها.
- صفحة `edit.html` المنشورة لا تغيّر الموقع: أي تعديل يبقى في متصفح من أجراه فقط. التحديث الفعلي يكون برفع `tree.json`.

## الجنس وزواج الأقارب (نوفمبر 2026)

- **أنثى**: خانة دائمة في المحرر. تغيّر «بن» إلى «بنت»، و«الزوجة» إلى «الزوج»، وتؤنّث صلات القرابة (ابنة عمك، خالتك…). زر **♀ تحديد الإناث** يقترح الإناث حسب الاسم دفعة واحدة.
- **زوج/زوجة من العائلة**: من لوحة الشخص ابحث عن زوجه في الشجرة واربطهما (الحقل `spouseId`). الأبناء يُكتبون مرة واحدة عند الأب، وتظهر عند الأم بطاقة «أبناؤها عند زوجها ←». زر **دمج الأبناء عند الأب** يوحّد الأبناء المكررين دون فقدان أحفادهم.
- **أبناء البنات المتزوجات من خارج العائلة**: للزوج من خارج العائلة خانتان: **اللقب** و**الاسم**. يُكتب نسب الأبناء «سليمان بن عيسى حمدي، وأمه لالة بنت يوسف»، وتُظهر بطاقتهم «اللقب: حمدي». أداة التنظيف تملأ اللقب والاسم تلقائيًا.
- **تعدد الزوجات**: زر «+ زوجة أخرى» في لوحة الشخص، ولكل ابن قائمة «الأم» يختار منها. البطاقة تجمع الأبناء حسب أمهاتهم.
- **🧹 تنظيف الأسماء** (المحرر): يحذف اسم عائلة الأب المكرر من أسماء أبناء البنات ويكتبه في خانة زوجها، مع معاينة قبل التطبيق.
- **📊 العائلة** (صفحة العرض): إحصاءات العائلة، وتبويب «ذكرى من رحلوا».
- `mobile-preview.html`: نموذج لعرض مخصّص للهاتف، للمعاينة فقط وغير مربوط بالموقع.

# شجرة العائلة 🌳

موقع ثابت من ثلاث صفحات، بلا خادم ولا قاعدة بيانات:

| الملف | الوظيفة |
|---|---|
| `index.html` | **واجهة العرض والتصفح** — هذا هو الرابط الذي تعطيه للآخرين. للقراءة فقط: تحريك وتكبير وبحث وطيّ الفروع. |
| `edit.html` | **واجهة التعديل** — تعديل الأسماء، السحب والإفلات، إضافة أبناء وآباء… |
| `tree.json` | **بيانات الشجرة العامة** التي تعرضها واجهة العرض. |

## النشر على GitHub Pages (مرة واحدة)

1. على github.com اضغط **New repository**، سمِّه مثلاً `family-tree`، واختر **Public** (الاستضافة المجانية تشترط ذلك).
2. افتح المستودع ثم **Add file → Upload files**، واسحب إليه الملفات الأربعة: `index.html` و`edit.html` و`tree.json` و`README.md` ثم **Commit changes**.
3. من **Settings → Pages**: في *Source* اختر **Deploy from a branch**، والفرع **main** والمجلد **/ (root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يعمل الرابط:
   - للعرض: `https://اسم-حسابك.github.io/family-tree/`
   - للتعديل: `https://اسم-حسابك.github.io/family-tree/edit.html`

## تحديث الشجرة بعد التعديل

1. عدّل الشجرة في ملفك الخاص على جهازك (`Family Tree.html`) أو في `edit.html`.
2. اضغط **🌐 نشر للعرض** ثم **تنزيل tree.json**.
3. في GitHub افتح المستودع ← **Add file → Upload files** وارفع `tree.json` الجديد (يستبدل القديم) ← **Commit**.
4. يظهر التحديث للزوّار خلال دقائق.

## الخصوصية — مهم

- أي شيء في مستودع عام يراه **كل من يملك الرابط أو يبحث عنه**. ملف `tree.json` يحتوي الأسماء والزوج/الزوجة والتواريخ والمكان.
- النسخة العامة **لا تتضمن** الملاحظات ولا بيانات الدراسة ولا الإنجازات ولا علامات «غير مؤكد». احتفظ بنسختك الكاملة في ملفك الخاص ولا ترفعها.
- صفحة `edit.html` المنشورة لا تغيّر الموقع: أي تعديل يبقى في متصفح من أجراه فقط. التحديث الفعلي يكون برفع `tree.json`.
